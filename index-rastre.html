Armazenamento local

Os dados ficam no localStorage deste navegador e deste dispositivo. Não são sincronizados entre usuários, computadores ou celulares. O GitHub Pages apenas hospeda os arquivos do site. Limpar os dados do navegador apaga os registros — faça backups com frequência.

O sistema só registra o que o usuário informa; não detecta movimentação física de bobinas.

Espaços extras são removidos e letras ficam maiúsculas; o restante da identificação não é alterado.
